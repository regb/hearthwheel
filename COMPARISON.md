# Feature comparison

Hearthwheel next to Mindustry, which is its measure for how complete a game of
the genre is. Compared are systems and what a player can do. Names, units,
machines, maps and looks are Hearthwheel's own, and no code or assets are
shared.

| Area | Mindustry | Hearthwheel |
| --- | --- | --- |
| Goods | 22, over two planets | 14, with hardness, burning and explosive ones |
| Fluids | 11, conduits, bridges, tanks | 3 (water, oil, brine), pipes, culverts, cisterns. They do not mix |
| Haulage | Conveyors, junctions, routers, sorters, overflow, bridges, unloaders, plastanium, mass drivers | Belts (3), crossings, splitters, sorters and strainers, spillways and weirs, ziplines, stores (2), hatches, catapults, burners. No bulk belt |
| Digging | Drills by tier, water boost, cultivators, pumps | Drills (3 tiers), sap taps, flax gardens, pumps |
| Crafting | ~20 crafters over both planets | 9, up to starglass |
| Power | ~12 generators, batteries, diodes, nodes, reactors that explode | 8 generators that follow the season, a reactor that bursts, flywheels, ratchets, pylons |
| Turrets | ~25, ammo types, coolant | 13, ammo types, water and brine as coolant |
| Support | Menders, overdrive, force projectors, mines, doors, point defense, tractor beams | Tinkers, metronome, aegis, caltrops, gates, swatter, grapnel |
| Walls | 6 materials and special ones | Copper, bronze, steel, starglass that throws shots back, gates |
| Units | ~55 in five tiers, naval, payloads | 16 automata in lines of up to four tiers, on the ground, in the air and on the water, with diggers, builders and menders. Boats dry out and freeze in with the seasons. No payloads |
| Unit control | Control groups, commands, stances, queues, possession | Groups, stances (fight, hold, patrol), queued routes, riding |
| The player | Mines, carries, deposits, shoots, builds, rebuilds | All of these |
| The core | Upgrades that change storage, unit and health | Three Hearths, each with more room, warmth, crew and a stronger lantern |
| Enemies | Wave generator, shields, guardians, bosses, enemy bases, RTS and base-building AI | Waves by season, shields, guardians, three bosses, Briar Hearts that put out hedges and spires; roots that spread over the land and gnaw at buildings; pods that hatch a brood, which guards them and marches with later waves; seeds that found new pods closer by. It does not design bases |
| Pathfinding | Flow fields by kind of movement, dynamic | Flow fields, changing with the seasons: lakes freeze, shallows dry |
| Status | ~20 effects, fires, puddles | Burning, slowed, chilled, frozen, shielded; fires that spread |
| Weather | Rain, snow, sandstorm, sporestorm | Seasons with rules of their own, and a storm for each |
| Automation | Processors with a language, displays, memory | Switches, governors, and looms that run up to eight if-then cards over linked buildings and four shared counters, with boards to show them. Not a general language |
| Campaign | Planet of sectors, launch pads, loadouts, research | A region of ten valleys, wagon posts, loadouts out of a vault, an almanac of pages, difficulty |
| Objectives | Scripted objectives and markers | A goal for each valley, a chain of rewarded aims, a tutorial, hints |
| Custom games | Rules, banned blocks, teams, PvP | Size, goal, threat, seasons, land, start, skies, waves. No teams |
| Map editor | Full, with objectives and scripts | Ground, seams, cliffs, hearts, mirror, undo, a name, rules, aims with rewards, play, share as text. No scripts |
| Layouts | Schematics with tags, text import | Copy, turn, flip, keep, share as text |
| Building aids | Auto junctions and bridges, pathfinding, replace, rebuild region, ghost blocks | All of these |
| Database | Every block, item, unit and status | Codex of buildings, goods and creatures |
| Saves | Slots, autosave, import and export | Slots, autosave for each valley, export and import as text |
| Settings | Audio, graphics, keys, language | Audio, graphics, keys, full screen. English and French |
| Achievements | Through Steam | 33 deeds |
| Statistics | Sector statistics | A ledger with graphs, and the end screen |
| Graphics | Shaders, bloom, lighting, parallax | Water and dome shaders, bloom, lights, cloud shadows, scorch marks, seasonal land |
| Multiplayer | Servers, PvP, co-op | None |
| Mods | Java, JavaScript, JSON | None |
| Platforms | Desktop, Android, iOS | JVM desktop, native desktop, browsers, with touch on phones. No mobile builds: the GameObject engine has no Android backend yet |

Seasons, warmth, the Great Wheel and the Almanac have no counterpart there.
